# Dereja Tura Engineering Website

## Project Overview

The Dereja Tura Engineering Website is a web application developed to present the company's services, projects, and business information online. It provides visitors with information about the company and a way to get in touch.

I worked mainly on the backend, developing APIs, managing database operations, and connecting the backend services with the frontend.

## Technologies Used

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **API:** REST API
- **Development:** JavaScript, Git

## Main Features

- Company information and website content management
- Project information management
- Engineering services management
- Contact request handling
- REST API integration between frontend and backend
- MongoDB database operations

## Backend Responsibilities

- Developed REST API endpoints using Node.js and Express.js.
- Created backend functionality for projects, services, and contact requests.
- Designed and managed MongoDB collections.
- Connected backend APIs with the frontend.
- Tested API functionality and fixed backend issues.

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ZekariyasT/Dereje_Tura_Engineering
   ```

2. Navigate to the project directory:

   ```bash
   cd Dereje_Tura_Engineering
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the root directory and configure your environment variables:

   ```env
   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

   If the project does not have a development script, use:

   ```bash
   npm start
   ```
